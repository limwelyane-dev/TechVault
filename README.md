TechVault — Full-Stack E-Commerce Platform

TechVault is a full-stack e-commerce web application for browsing products, managing a shopping cart, placing orders, and managing inventory through an admin dashboard.

Features

- User registration and login
- Product browsing and product management
- Shopping cart and checkout
- Customer order history
- Admin dashboard and order management
- Product image uploads
- Product reviews

Tech Stack
Frontend: React, Vite, Tailwind CSS, TanStack Query

Backend: Node.js, Express.js

Database: PostgreSQL

Deployment: Vercel and Render

Other tools: Git, GitHub, Cloudinary, JWT

What I Learned

- Building a full-stack application using React and Express
- Designing REST API endpoints
- Connecting PostgreSQL to a backend server
- Implementing authentication and role-based authorization
- Deploying a frontend and backend separately
- Configuring production environment variables and CORS
